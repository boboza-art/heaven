## 当前方案要点（v3.5）

- **形态**：双锥形柱 120cm + **柱底 Ø40–45cm 扩张扁盘**（分离"行程"与"受力面"，解 P-phys3 力不足矛盾）
- **充气**：混合式 hybrid（烟火引发+冷气降温）+ 环形注入；具体发生器/歧管待立项后定
- **材料**：多级分级——近端尼龙66硅涂层（耐高温）→ 远端柔性 TPU/Dyneema 夹层（耐温120°C，气体已降温）
- **泄压**：柔性材料本体弹性 + 自适应孔洞（削峰+阻尼）+ 爆破片（超压兜底）
- **工作压**：0.4–0.5atm 表压（配合扁盘接触面，力足够）
- **后背/头保护**：EPP 泡沫护颈圈 + 尾气导流背板气囊（~+150g，复用主气源）
- **触发**：高度表预警级（提前20-100m）+ 近地确认级
- **收纳**：整机 ~1L，可集成进坐包
- **伤害减免**（90kg，平均减速度）：15 m/s ≈ 9.6g；⚠️ 真实峰值为平均值 1.5–2 倍（P-phys1）

> **设计边界**：只防垂直坠落（8–20 m/s 垂直分量）。水平撞击（贴坡/撞山）是盲区（P-phys4），暂不覆盖。
