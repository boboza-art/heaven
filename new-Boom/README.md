## 当前方案要点（v3.4）

- **形态**：双锥形柱（下细上粗 4:1，几何抗侧翻），行程 120cm（+柔性变形等效 130cm）
- **充气**：双 60L 烟火发生器，独立驱动双柱（同步 + 冗余 + 产气翻倍）
- **材料**：TPU 复合 Dyneema 夹层薄膜（超薄 0.08mm、抗撕、可弹性大变形吸能）
- **泄压**：柔性材料本体弹性（主）+ 自适应孔洞（限幅+阻尼）+ 爆破片（超压兜底）；取消一次性逐级破裂缝
- **工作压**：0.3–0.5atm 表压（低压更安全）
- **收纳**：整机 ~1L，可无感集成进坐包；瓶颈是发生器（刚性不可压）
- **伤害减免**（90kg）：8–18 m/s 均 ≤13g（轻微可存活），20 m/s 15.7g；全区间降幅 ~96%
